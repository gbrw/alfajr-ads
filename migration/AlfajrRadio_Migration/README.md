# حزمة ترحيل Alfajr Radio ← Ads Alfajr Manager

| المجلد | المحتوى |
|---|---|
| `assets/adhan` | أذان عراقي بصوت الشيخ مصطفى رعد العزاوي (`adhan_iraqi_azzawi.mp3`) |
| `assets/azkar` | أذكار الصباح والمساء بصوت القارئ أحمد النفيس |
| `assets/ads` | إعلان الإغلاق (`ad_closing.wav`) |
| `assets/pre-adhan` | تنبيه قبل الأذان: الظهر والعصر والمغرب والعشاء (الفجر غير متوفر) |
| `data/prayer-times.csv` | مواقيت الرمادي لـ 366 يوماً، بنظام 12 ساعة (AM/PM) بعد التصحيح |
| `data/*.json` | الإعلانات والأذكار والأذان والإعدادات بمسارات نسبية |
| `legacy/` | النسخ الأصلية دون تعديل (JSON وملفا Excel) |

## ملاحظات
- ملف Excel الشهري وملف `الرمادي_2021` يحتويان **نفس الأوقات** (372 صفاً متطابقة)، بتنسيقين مختلفين.
- تنبيه الفجر: الملف الأصلي كان خارج الأرشيف، والفجر معطّل أصلاً بسبب ساعات العمل (07:00 AM – 12:00 AM).
- الأسماء العربية الطويلة للملفات الأصلية استُبدلت بأسماء إنجليزية قصيرة تجنباً لمشاكل الحفظ.
- أذكار الصباح والمساء في `data/azkar.json` مجدولة نسبةً للشروق والمغرب (30 و15 دقيقة مؤقتاً، يحددها المشرف).
- كل الأوقات في الحزمة بنظام 12 ساعة.
